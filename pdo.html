PDO (폴리디옥사논)
Polydioxanone · 콜라겐 부스터 · 의료용 봉합사 → 나노 필러·화장품
PDO란?
콜라겐 합성 유도 — 3단계
  • ① 가수분해 — PDO가 체내 수분과 만나 에스테르 결합이 끊어지며 천천히 분해. 최종 산물은 이산화탄소+물 → 체내 잔류 없음
  • ② 미세 염증 반응 — 분해 과정에서 주변 조직에 경미한 염증 유발 → 대식세포 활성화 → TGF-β·VEGF 등 성장인자 분비
  • ③ 섬유아세포 활성화 — TGF-β 신호 → Type 1·3 콜라겐 합성. VEGF 신호 → 혈관신생 → 혈색·광채 개선 (PDLLA에 없는 PDO만의 강점)
구형 PDO 약점 → 울트라콜 개선 포인트

  • 결절 발생 리스크

시술 기준 타임라인
시술 직후 ~ 2주
약간의 붓기·멍. PDO 미세구 진피층 정착.
1~2개월
가수분해 시작 → TGF-β·VEGF 분비 → 섬유아세포 활성화. 탄력·결 개선 체감 시작.
3~6개월
콜라겐 합성 피크. 탄력·광채·혈색 개선 극대화.
6~12개월
PDO 완전 분해. 생성된 콜라겐 약 12개월 유지. PDLLA 대비 분해 빠름 → 유지 기간 짧음.
주요 효능
  • Type 1·3 콜라겐 합성 촉진 → 피부 탄력·볼륨 개선
  • VEGF 분비 → 혈관신생 유도 → 피부 혈색·광채 개선 (PDLLA·PLLA에 없는 PDO만의 차별점)
  • TGF-β 경로 → 섬유아세포 활성화 → 진피 리모델링
  • 생분해성 → 이산화탄소+물로 완전 분해. 체내 잔류 없음
  • 나노 분산 → 도포형 화장품 경피 흡수 가능 (표피~진피 상층)
주의점
  • 화장품 ≠ 시술 효과 — 나노 PDO 화장품은 진피 깊은 층 리모델링 어려움. 시술 보조·표피 효과 수준
  • 유지 기간 짧음 — 6~8개월로 PDLLA·PLLA 대비 짧아. 장기 유지 원하면 반복 시술 필요
  • 결절 리스크 — 나노화로 감소했지만 0은 아님. 시술 후 마사지 프로토콜 준수 필수
  • 임상 근거 격차 — PLLA(25년) 대비 나노 PDO 필러 임상은 아직 제한적
  • 임신·수유 중, 자가면역 질환, 켈로이드 체질 주의

PDO 제품 검색
PDO는 콜라겐 부스터 4형제 안에서 PDLLA·PLLA·PCL과 비교해서 포지션이 명확해져.
PDLLA (쥬베룩)
같은 카테고리비교 필수
공통점: 콜라겐 부스터, 생분해성, TGF-β 경로.
차이점: PDO = 봉합사 유래·가수분해 기전 + VEGF 혈관신생. PDLLA = 폴리젖산·이물반응 + HA 복합 즉각 보습.
분해: PDO 6~8개월 vs PDLLA 12~18개월.
💡 PDO는 "혈색·광채", PDLLA는 "잔주름·즉각 보습"으로 포지션 차별화 가능. → PDLLA 카드 보기
PLLA (스컬트라)
같은 카테고리
공통점: 콜라겐 부스터, 생분해성.
차이점: PLLA = 25년 임상 근거·깊은 볼륨 복원. 50대+ 적합. PDO = 분해 빠르고 화장품화 앞서. 30~40대 탄력·광채 적합.
💡 PDO는 "예방적 항노화", PLLA는 "볼륨 복원"으로 타깃 세분화.
PCL (폴리카프로락톤)
비교 성분
공통점: 생분해성 봉합사 유래 콜라겐 부스터.
차이점: PCL = 분해 가장 느림(24~36개월). 엘란쎄 대표 제품. PDO가 PCL보다 효과 체감 빠르고 화장품화 앞서.
분해 속도 순: PDO < PDLLA < PLLA < PCL.
💡 4형제 중 유지 기간 원하면 PCL·PLLA, 빠른 체감 원하면 PDO.
PN / PDRN (리쥬란)
조합 추천
공통점: 진피 재생·콜라겐 합성 촉진.
차이점: PN = DNA 유래 핵산 → 세포 증식·ECM 환경 복원. PDO = 가수분해 → TGF-β·VEGF → 콜라겐+혈관신생. 기전이 달라 시너지 기대.
💡 PDO 시술 후 PN 홈케어 세럼 조합이 재생 환경 지지에 효과적.
!
콜라겐 부스터 중복 시술
주의
PDO·PDLLA·PLLA·PCL 짧은 간격 중복 시술 시 결절·육아종 리스크 증가. 콜라겐 과잉 자극으로 피부 딱딱해질 수 있음.
동일 부위 재시술 간격 4~6주 이상. 다른 콜라겐 부스터 병용 시 전문의 판단 필수.
📊 시장 반응 요약 — 2025년 기준
글로벌PDO 필러 시장 2032년 299억 달러 전망
2024년 191억 달러 → 2032년 299억 달러 (CAGR 5.72%). 안면 회춘 55% 차지. 비수술 미용 시술 수요가 성장 주도.
국내울트라브이 스팩 상장 추진 — PDO 시술 시장 성장
울트라콜 2024년 매출 73억 원(전체 43%). 기업가치 690억 원 산정. 화장품 비중 감소(40%→12%), 시술 중심으로 재편. 유사 경쟁 제품 증가로 경쟁 심화.
트렌드콜라겐 부스터 4형제 포지션 경쟁 본격화
PDO·PDLLA·PLLA·PCL이 각각 다른 분해 속도·강점으로 경쟁. "어떤 콜라겐 부스터를 왜 쓰는가" 설명할 수 있는 기획력이 중요해지는 시장.
✅ 써봐 — 이런 목적이라면
30~40대 예방적 항노화. 피부 탄력·광채·혈색 동시 개선 목적. 효과 빨리 체감하고 싶은 경우. 시술 후 홈케어 루틴 원하는 경우. → 시술(울트라콜)로 접근, 홈케어는 나노 PDO 화장품+PN 세럼 조합.
⚠️ 화장품 기대치는 현실적으로
나노 PDO 화장품은 표피~진피 상층 보조 효과. 시술 전후 홈케어·유지 목적으로 접근. 울트라브이 화장품 매출 감소는 소비자 기대 관리 실패 측면도 있음.
❌ 재고 — 이런 경우는
깊은 안면 볼륨 복원이 목적 → PLLA(스컬트라)가 더 적합. 2년 이상 장기 유지 원하면 PCL·PLLA 고려. 화장품에서 시술급 효과 기대 → 기대 관리 필수.
기초 기획자 관점
PDO의 핵심 차별점은 VEGF 혈관신생이야. 콜라겐 합성은 PDLLA·PLLA도 하지만, 혈관신생으로 피부 혈색·광채까지 잡는 건 PDO만의 강점. "피부 속부터 환해지는" 포지셔닝이 가능한 성분이야.

화장품화는 가장 먼저 시도했지만 대중화가 더딘 상황. PN이 걸어온 대중화 경로(시술 → 화장품 → 올리브영)를 PDO가 따라갈 수 있을지가 관건. VEGF 혈관신생 포지션을 잘 살리면 차별화된 기초 라인 기획이 가능해.

체크리스트
  • PDO가 의료용 봉합사에서 시작한 성분임을 설명할 수 있다
  • 가수분해 → TGF-β·VEGF → 콜라겐+혈관신생 기전을 말할 수 있다
  • PDO vs PDLLA vs PLLA 분해 속도 순서를 안다
  • PDO 차별점이 VEGF 혈관신생임을 이해했다
  • 콜라겐 부스터 4형제를 분해 속도 순으로 나열할 수 있다
  • 울트라콜이 "세계 최초 PDO 필러"라는 포지션임을 안다
